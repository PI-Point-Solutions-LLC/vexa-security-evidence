# VE×A Sanitized Vendor Assurance Register

Reviewed: 2026-08-21

VE×A maintains a detailed private inventory of service providers, data processors, software dependencies, investigative-data sources, contracts, access scopes, security evidence, incident contacts, and review decisions. Provider identities are not automatically published when doing so would expose private architecture or investigative capability.

| Vendor class | Security objective | Current public status | Remaining maturity work |
| --- | --- | --- | --- |
| Hosting and application delivery | Protect availability, releases, and customer-facing delivery | IMPLEMENTED — VALIDATION CONTINUING | Recurring assurance and broader failure exercises |
| Database, identity, and evidence metadata | Protect authorization, isolation, integrity, and audit records | IMPLEMENTED — VALIDATION CONTINUING | Periodic privileged-access and recovery review |
| Private storage and isolated processing | Protect original evidence and fail-closed processing | IMPLEMENTED — VALIDATION CONTINUING | Restricted-data and sustained-capacity assurance |
| Transactional communications | Protect account and security messaging | PARTIALLY IMPLEMENTED | Complete delivery, abuse, and incident-response validation |
| Investigative data and enrichment providers | Preserve lawful scope, provenance, uncertainty, contractual use, and cost control | PARTIALLY IMPLEMENTED | Complete entitlement and recurring source-family reviews |
| Development and software supply chain | Protect source, builds, dependencies, and releases | IMPLEMENTED — VALIDATION CONTINUING | Continuous dependency and access assurance |

Detailed provider names, account identifiers, contractual terms, capability inventories, credentials, topology, findings, and remediation records remain restricted. A provider is not treated as approved merely because an account or credential exists.
